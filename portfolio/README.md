# Portfólio Pessoal — Caio Faria Civitarese

Site pessoal responsivo para apresentar habilidades, projetos e
experiência como desenvolvedor Front-End.

## Estrutura

```
portfolio/
├── index.html
├── css/
│   ├── style.css        → tokens, layout e componentes
│   ├── animations.css    → transições e reveal on scroll
│   └── responsive.css    → breakpoints tablet/mobile
├── js/
│   └── script.js         → menu mobile, efeito de digitação, scroll reveal
└── README.md
```

## Como visualizar

Basta abrir `index.html` em qualquer navegador — não há dependências
de build. As fontes (JetBrains Mono e Inter) são carregadas via
Google Fonts.

## Seções

1. **Hero** — apresentação com terminal animado.
2. **Sobre mim** — trajetória e objetivos.
3. **Habilidades** — linguagens e ferramentas com barras de proficiência.
4. **Projetos** — cards com miniatura, tags e links.
5. **Contato** — GitHub, LinkedIn e email.
